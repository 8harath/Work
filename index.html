Prologue

Kunthive is a small studio in Bengaluru. We build websites for businesses, the software those businesses run on, and a set of open-source experiments that mostly started as problems we hit ourselves.

You don’t need to be technical to read this. The work divides into three honest kinds. The first is a website — a driving school, a builder, a school, a bakery. Each one starts with a written brief (who buys, what they need to see, what counts as a result) before anyone opens a code editor. The site has to load fast on a cheap phone and be easy for the owner to run without us.

The second is what sits behind the front door: tracking leads, marking attendance, calculating payroll, chasing renewals. We build those systems too, including the one that runs our own studio, which we use every single day and which replaced our Notion workspace entirely.

The third is Kunthive Labs, where we find out what AI can honestly do. Instead of guessing, we build: a funding database with 14,700 verified deals, a safety test harness for AI agents, a typography search engine. Most of it is open source, so you can read the code and judge for yourself rather than take our word for it.

This report is ordered by distance from a paying client. Act 01 is work someone paid for. Act 05 is work nobody has asked for yet. Anything unfinished is labelled as unfinished, because a list that only shows the wins is not a list worth reading.

Appendix
